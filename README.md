# Wizard-Punkteblock

Digitaler Punkteblock für 3–6 Spieler nach den Wizard-Standardregeln.

## Funktionen
- Automatische Punkteberechnung und Stichprüfung
- Dunkelmodus mit gespeicherter Auswahl
- Animierte Kartengeber-Markierung und hervorgehobene erste Vorhersage
- Große Kartenanzahl pro Spieler und Führungskrone
- Lokales Spielarchiv mit JSON-Export und -Import

## Start
https://clausi1971.github.io/wizard-punkteblock/

Alternativ index.html im Browser öffnen. Keine Installation und kein Build erforderlich.

Spiele werden ausschließlich im verwendeten Browser gespeichert. Für einen Gerätewechsel die Sicherung exportieren und importieren. Daten der vorherigen Website lassen sich über denselben Weg übernehmen.

Unabhängiges Fanprojekt; keine Verbindung zu AMIGO.
